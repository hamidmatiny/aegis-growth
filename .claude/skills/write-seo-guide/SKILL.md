# Write SEO Guide

## Purpose

Produce a real, useful SMB-security guide draft targeting a real search query, for publication on AEGIS property (`defenseaegis.org` / product docs). This is **autonomous-safe**: own site, no third-party reputation risk.

## Pace honesty

Zero-budget organic SEO is a **weeks-to-months** channel. One guide does not move MRR. Do not overclaim.

## Process

### Step 1: Pick a real query

Choose a specific SMB/security intent AEGIS can honestly answer (e.g. “how to check CVE exposure for small business servers”, “prompt injection basics for SMB IT”). Avoid keyword stuffing.

### Step 2: Draft

Write `memory/seo-drafts/<slug>.md` with:

- Target query + intent
- 800–1500 words plain-language guide
- Clear CTA toward AEGIS product capabilities that actually exist (no vapor)
- Sources/links only when verified

### Step 3: Hand-off for publish

Publishing to the live site may require Hamid/repo write. File the draft path + summary; escalate publish request to `aegis-ceo` if you lack write access. Do **not** invent that it is live.

### Step 4: Slack + report

Post draft location to `#aegis-growth`. Optional `aegis_growth.seo_draft`.

## Final step — Slack close-out (mandatory)
