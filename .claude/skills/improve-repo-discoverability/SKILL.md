# Improve Repo Discoverability

## Purpose

Make `github.com/hamidmatiny/aegis` easier to find. Prefer changes that are truthful and reviewable.

## Process

### Step 1: Audit

Check current README clarity, topics, description. Note gaps in `memory/repo-discoverability.md`.

### Step 2: Propose or apply safe edits

- README polish drafts → PR/request via CEO/Hamid if no write token
- GitHub topics: propose the exact topic list; apply only with granted write access
- Awesome-list PRs: draft PR text; submit only to lists that accept PRs and match the project — no spam

### Step 3: Track + Slack

Record what shipped vs what is waiting on Hamid. `#aegis-growth` close-out.

## Final step — Slack close-out (mandatory)
